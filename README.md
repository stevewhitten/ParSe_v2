# ParSe_v2
ParSe v2 uses an optimal set of amino acid property scales for fast predictions of domain-level structure and gives a simple, quantitative metric for the sequence-calculated phase separation potential.

An HTML implementation can be used at stevewhitten.github.io/Parse_v2_web/

To analyze more than one sequence, use stevewhitten.github.io/Parse_v2_FASTA/
